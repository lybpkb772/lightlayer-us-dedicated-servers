## 这台 $40 的机器能跑什么，跑不动什么

E5-2660 是 8 核 16 线程的老一代至强，单核性能放到今天不算强，多核跑并发请求还行。8GB 内存是这台机器最明显的短板：装个宝塔面板、跑一套 WordPress 加 MySQL，内存占用就去掉一半；再叠 Redis、Node 服务或多站点，很快就到顶。

以下场景适合这台机器：日访问量几千到一两万的企业站、外贸独立站；跨境店铺的 ERP 后台、订单同步脚本；需要固定 2 个干净 IPv4 的轻量业务；做代理中转、API 转发这类吃带宽不吃内存的活。

不太适合的场景：日活用户上万的电商主站；跑 AI 推理、视频转码；需要开十几个容器或虚拟机的业务；单机跑大型数据库。这些场景要么加内存，要么直接换双路机型，$40 这档省下的钱会在排查卡顿上还回去。

## 50M 优化、200M 全向、300M 国际：三条线怎么选
